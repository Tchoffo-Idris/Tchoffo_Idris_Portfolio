## Deploy to GitHub Pages

This is a static website, so it can be hosted directly from this repository without a build step.

1. Push the project files to the `master` branch of [Tchoffo-Idris/Tchoffo_Idris_Portfolio](https://github.com/Tchoffo-Idris/Tchoffo_Idris_Portfolio).
2. Open the repository on GitHub and go to **Settings** > **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `master` branch and the `/ (root)` folder, then click **Save**.
5. Wait for GitHub to publish the site.

The portfolio will be available at:

<https://tchoffo-idris.github.io/Tchoffo_Idris_Portfolio/>

The homepage must remain named `index.html` at the repository root for GitHub Pages to load it correctly.

## Run Locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.

For a local development server, run the following from the project directory if Python is installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.
